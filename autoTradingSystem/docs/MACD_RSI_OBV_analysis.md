## 선택 구간(13:26~13:40) 매수 미발생 원인 분석

데이터 선택 구간은 XRP 대형 Surge(13:40, 거래량 1,573,096 XRP) 직전 구간입니다.  
매수 시그널이 발생하지 않은 구체적 원인:

### Phase 1: 13:26~13:30 — Golden Cross 없음 + OBV 하락 (2중 실패)

```
13:05 매수 이후 MACD가 Signal 위로 상승 → 13:15에 Death Cross 발생
선택 구간 진입 시점 MACD 값:
  13:26: MACD=+0.012, Signal=+0.225  → 아직 Signal보다 한참 아래
  13:29: MACD=-0.209, Signal=+0.004  → MACD 음수 전환
  13:30: MACD=-0.079, Signal=-0.024  → 여전히 Signal 미도달
OBV_MA: 13:17 이후 지속 하락 중
```

### Phase 2: 13:31 — Golden Cross 발생! 그러나 RSI=57.1 (임계값 초과)

```
13:31은 유일하게 Golden Cross가 발생한 순간이었으나:
  - RSI = 57.1  → 기준 55.0 대비 단 2.1 포인트 초과
  - OBV_MA: 이 봉에서 잠깐 상승 확인 — 조건 충족
  즉, Golden Cross(Y) + RSI<55(N, 57.1) + OBV(N) → 2중 실패
```

**13:31은 RSI 2.1 포인트 차이로 매수 시그널을 놓친 가장 아쉬운 봉입니다.**

### Phase 3: 13:32~13:40 — 급등 시작, RSI 폭등 (66 → 100)

```
가격: 2033 → 2035 → 2036 → 2047 (Surge)
RSI : 66.7 → 75.0 → 100.0 으로 즉시 과매수 돌입
MACD: Signal 위에 이미 있어 새 Golden Cross 불가
```

### 결론

|------|-----------|
| **① Death Cross 후 상태** | 13:15 Death Cross로 MACD < Signal 구간 진입, 새 GC까지 13:31까지 대기 |

**전략적 해석**: 전략이 13:05에 이미 surge 35분 전에 선진입한 것이 핵심입니다.  
13:26~13:40 구간은 이미 매수 포지션이 유지되어야 할 시점이며, 이 구간에서  
새 매수 시그널이 없는 것은 **전략이 의도한 정상 동작**입니다.

## 전략 특성 요약

### 강점
- **Surge 선행 감지**: 대형 급등(13:40) 35분 전(13:05)에 진입 포착
- **노이즈 필터링**: RSI + OBV 이중 확인으로 허위 시그널 차단 (13:17~13:30 동안 무신호 유지)
- **3중 필터 구조**: Golden Cross(추세) + RSI(모멘텀) + OBV_MA(거래량) 상호 보완

### 주의사항
- RSI 임계값(55)이 민감하여 급등 직전 구간(13:31)을 간발 차로 놓칠 수 있음
- 1분봉 특성상 매도 시그널이 집중 구간에서 연속 발생할 수 있음 (18:42~19:09)
- OBV_MA 기간이 짧아(10) 단기 거래량 노이즈에 영향받을 수 있음
